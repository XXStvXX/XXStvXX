I use AI as a structured collaborator across research, planning, implementation, and review—not as a substitute for judgment. My typical workflow is:

1. **Research and context:** use tools such as Gemini to gather public background information and identify relevant sources.
2. **Planning and critique:** use ChatGPT to clarify requirements, compare approaches, and challenge assumptions.
3. **Implementation and delivery:** work with Codex to build, test, document, and refine code and project artifacts.
4. **Bilingual review:** use DeepSeek and other language tools to support English–Chinese drafting and terminology checks.
5. **Human verification:** inspect sources, test outputs, correct technical claims, and make the final product and career decisions myself.
